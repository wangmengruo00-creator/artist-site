# The Three Metamorphoses / 精神三变 - Presentation Notes

The Three Metamorphoses can currently be shown in three ways:

## 1. Portfolio Website Mode

- Project intro
- Enter field interaction
- Short project note
- Documentation images / video later

## 2. Prototype Demo Mode

- Fullscreen field
- Mouse interaction
- Camera presence enabled
- Short screen recording for documentation

## 3. Future Installation Mode

- One main screen or laptop showing the interactive field
- Optional side screens showing related field states
- Viewer interacts through mouse, body presence, and possibly later M5Stack input

## Current Prototype Focus

- Mouse as memory writing
- Camera as bodily disturbance / rupture
- Stillness as breathing and residue

## Future Layers

- Sound as pressure / burden
- M5Stack as physical play / child-like generation
